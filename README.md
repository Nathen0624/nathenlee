# Nathen Lee — Portfolio

A static, single-page portfolio site. No build step: open `index.html` in a browser.

## Files
- `index.html` — the whole site (HTML, CSS and a small script)
- `assets/headshot.png` — headshot
- `assets/pricing-demo.png` — Pricing Board demo screenshot
- `assets/Nathen_Lee_Resume.pdf` — resume linked from the Résumé button

## Editing content
Projects and the Journey section are defined in the `COLUMNS` and `JOURNEY` arrays near the bottom of `index.html`.
Two projects still need links (marked `TODO`): NYC Boba Site Selection and S&P 500 Sector Performance.

## Notes
- Project links point to Claude artifacts. Each one must be shared as "anyone with the link" or visitors can't open it.
- The contact form opens the visitor's email app. To receive messages directly, connect Formspree or Netlify Forms.
- The background is an inline SVG illustration; the comment above it explains how to swap in a photo.

## Deploy
Any static host works: GitHub Pages, Vercel or Netlify.
